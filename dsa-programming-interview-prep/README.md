# Data Structures, Algorithms, and Programming Interview Prep

This folder contains interview-ready practice material for data structures, algorithms, and programming rounds.

## Start Here

| File | Use it for |
| --- | --- |
| `DSA_SOLVING_GUIDE.md` | How to approach coding interview problems |
| `dsa-interview-questions.md` | 150 DSA questions grouped by topic and difficulty |
| `programming-interview-questions.md` | Practical programming questions often asked in interviews |
| `company-style-dsa-questions.md` | Company-style DSA and coding questions |
| `progress-tracker.md` | Track solved, revision, and weak topics |
| `playground/` | Local Python playground to solve and validate coding problems |

## Practice Path

### 30-Day Plan

1. Days 1-5: Arrays, strings, hashing, two pointers
2. Days 6-10: Stack, queue, linked list, binary search
3. Days 11-15: Trees, heaps, intervals
4. Days 16-20: Graphs, BFS, DFS, topological sort
5. Days 21-25: Dynamic programming and backtracking
6. Days 26-30: Company-style mixed practice and timed mocks

## Local Playground

List available problems:

```bash
python3 dsa-programming-interview-prep/playground/validate_solution.py --list
```

Validate an example solution:

```bash
python3 dsa-programming-interview-prep/playground/validate_solution.py --problem p001 --file dsa-programming-interview-prep/playground/solutions/p001_example.py
```
