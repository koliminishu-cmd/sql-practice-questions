# Programming Interview Questions

These questions test clean coding, problem decomposition, debugging, and practical engineering ability.

## Core Programming

1. Implement a function to deeply flatten a nested list.
2. Implement a function to chunk a list into fixed-size groups.
3. Implement debounce and throttle behavior.
4. Parse a CSV line while handling quoted commas.
5. Validate whether a string is valid JSON-like brackets.
6. Implement a basic calculator for `+`, `-`, `*`, and `/`.
7. Convert snake_case keys in a dictionary to camelCase recursively.
8. Implement retry with exponential backoff.
9. Implement a simple rate limiter.
10. Implement a function memoizer.

## Data Processing

11. Given log lines, count requests per endpoint.
12. Given log lines, calculate p95 latency per endpoint.
13. Given a list of events, sessionize them by user with a 30-minute gap.
14. Deduplicate records by ID and keep the latest timestamp.
15. Reconcile two lists of transactions and find mismatches.
16. Merge multiple sorted event streams.
17. Detect missing sequence numbers in a stream.
18. Group events by time window.
19. Find top K frequent words in a large file.
20. Implement pagination over a sorted list.
