# Company-Style DSA and Programming Questions

These questions are inspired by common interview patterns. They are not guaranteed exact company questions.

## Amazon-Style

1. [ ] Find the top K frequent products from a stream of order events.
2. [ ] Merge overlapping delivery time windows.
3. [ ] Find the minimum number of delivery agents needed for intervals.
4. [ ] Design an LRU cache for recently viewed products.
5. [ ] Given package dependencies, return a valid installation order.
6. [ ] Find the shortest path in a warehouse grid with blocked cells.
7. [ ] Implement autocomplete for product search.
8. [ ] Find pairs of orders whose total weight equals a truck capacity.
