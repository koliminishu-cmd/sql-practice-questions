# Interview Practice Repository

This repository contains interview preparation material for data engineering, SQL, data structures, algorithms, and programming rounds.

## Folders

| Folder | Contents |
| --- | --- |
| `sql-practice-questions/` | SQL interview questions, company-style SQL prompts, and a SQLite validation playground |
| `dsa-programming-interview-prep/` | DSA questions, programming questions, company-style coding prompts, and a Python validation playground |

## Quick Commands

SQL playground:

```bash
python3 sql-practice-questions/playground/validate_query.py --list
```

DSA playground:

```bash
python3 dsa-programming-interview-prep/playground/validate_solution.py --list
```
